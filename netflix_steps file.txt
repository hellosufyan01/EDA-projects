# 16.2 Content Era

Create broad release-year groups.

```python
def release_era(year):
    if year < 1980:
        return "Before 1980"
    elif year < 2000:
        return "1980-1999"
    elif year < 2010:
        return "2000-2009"
    elif year < 2020:
        return "2010-2019"
    else:
        return "2020+"
```

Apply:

```python
df["release_era"] = df["release_year"].apply(release_era)
```

Check:

```python
df[[
    "release_year",
    "release_era"
]].head(20)
```

### Important student note

Correlation here should be interpreted carefully.

For example:


### The key difference from the Titanic lab

**Titanic** teaches students mainly about **missing numerical/categorical data, outliers, encoding, and survival relationships**.

**Netflix** adds the next level:

* messy strings
* multi-value columns
* dates
* extracting year/month
* splitting Movie vs TV Show
* extracting numbers from text
* exploding multi-country data
* genre simplification
* content-age features
* time-series-style analysis
* dashboard construction
