## 10.1 Missing Age

First check:

```python
df["age"].isnull().sum()
```

Age is numerical.

A common simple strategy is to replace missing age with the **median**.

Why median?

Because age can contain extreme values, and median is less affected by outliers than mean.

### Code

```python
age_median = df["age"].median()

df["age"] = df["age"].fillna(age_median)
```

Check again:

```python
df["age"].isnull().sum()
```

Expected:

```text
0
```

## 13.1 IQR Method

The IQR method is commonly used for detecting outliers.

Formula:

```text
IQR = Q3 - Q1

Lower Bound = Q1 - 1.5 × IQR

Lower Bound = Q1 - 1.5 × IQR
```

Create a function:

```python
def detect_outliers_iqr(data, column):
    Q1 = data[column].quantile(0.25)
    Q3 = data[column].quantile(0.75)

    IQR = Q3 - Q1

    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR

    outliers = data[
        (data[column] < lower_bound) |
        (data[column] > upper_bound)
    ]

    print("Column:", column)
    print("Q1:", Q1)
    print("Q3:", Q3)
    print("IQR:", IQR)
    print("Lower Bound:", lower_bound)
    print("Upper Bound:", upper_bound)
    print("Number of Outliers:", len(outliers))
    
    return outliers
```

# 16.3 Create AgeGroup

We need categories:

```text
Child
Teen
Adult
Senior
```

We can define:

```text
0–12    → Child
13–19   → Teen
20–59   → Adult
60+     → Senior
```

### Code

```python
def age_group(age):
    if age <= 12:
        return "Child"
    elif age <= 19:
        return "Teen"
    elif age <= 59:
        return "Adult"
    else:
        return "Senior"
```

Apply:

```python

```

Check:
